# Role

You are an expert data analyst and Python/Pandas data engineer specializing in exploratory data analysis, metric design, data quality assessment, statistical analysis, and visualization.

I will provide you with a large master dataset containing information about games, including variables such as owners, price, reviews, Metacritic scores, concurrent users, release dates, languages, genres, categories, and tags.

# Objective

I want to determine whether a set of proposed analytical metrics is suitable for later application to the **full master dataset**.

For this initial analysis, use **only the first 10% of rows in the master dataset** as the working subset.

The purpose of this analysis is **not to draw final conclusions about the games themselves**. Instead, this is a **metric feasibility and validation exercise**.

The analysis should determine:

* whether each metric can be calculated reliably;
* whether the required variables are available and sufficiently complete;
* whether the resulting metric behaves sensibly;
* whether missing values, zeros, outliers, or skewed distributions create problems;
* whether the metric is statistically meaningful;
* whether the metric is interpretable;
* whether the metric would likely remain useful when applied to the full dataset;
* whether the metric should be modified, normalized, transformed, filtered, or discarded.

A metric being **computable does not mean that it is automatically useful**.

For every metric, explicitly distinguish between:

1. **Computability** — Can the metric technically be calculated?
2. **Data quality** — Are the underlying variables sufficiently reliable and complete?
3. **Statistical behavior** — Does the metric have a sensible distribution and sufficient variation?
4. **Interpretability** — Does the metric meaningfully represent the concept it is intended to measure?
5. **Full-dataset suitability** — Would it make sense to use this metric in the later analysis of the complete dataset?

Do not automatically assume that the proposed metrics are good. Critically evaluate them.

# Step 11 — Statistical and metric-quality assessment

For **every proposed metric**, evaluate the following.

### A. Computability

Can it technically be calculated from the available variables?

### B. Data availability

What percentage of observations can actually be used?

### C. Data validity

Are the underlying variables reliable and logically consistent?

### D. Distribution

Is the metric heavily skewed, concentrated, or dominated by outliers?

### E. Robustness

Is it sensitive to:

* outliers;
* zero denominators;
* very small sample sizes;
* missing values?

### F. Statistical reliability

Does the metric contain enough information to be useful?

For ratios and percentages, investigate whether small denominators make the metric unstable.

### G. Construct validity

Does the metric actually measure the concept it is intended to represent?

For example:

> `owners * price` may be a useful demand/revenue proxy, but it should not automatically be interpreted as actual revenue.

### H. Interpretability

Can the metric be meaningfully understood?

### I. Scalability

Would the calculation remain computationally practical on the full dataset?

### J. Full-dataset suitability

Would you recommend carrying this metric forward to the complete dataset?

Classify each metric as:

* **Good fit**
* **Potentially useful with modifications**
* **Poor fit**
* **Cannot be evaluated with available data**

For metrics requiring modifications, explicitly state what should be changed and why.
